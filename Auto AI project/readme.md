# THE INSTITUTION + THE FOUNDRY

An autonomous AI organisation that generates revenue, preserves knowledge,
and adapts to its founder's energy — built to run 24/7 on free-tier
infrastructure, governed by an immutable constitution.

**Not a chatbot. Not a content mill. An organisation.**

---

## What this is

A three-layer system:

1. **The Institution (governance)** — Constitutional Court, Steward
   (meta-agent), Oracle (predictions), Library (memory), Safety Officer,
   Security Buffer. Keeps the system safe, coherent, and enduring.
2. **The Foundry (revenue)** — 11 autonomous revenue streams, each with
   its own agent, metrics, and kill criterion: SEO content sites, digital
   products, faceless video, newsletter, grants, freelance, print-on-demand,
   affiliate sites, social media, micro-SaaS, stock content.
3. **The Meta-Agent (recursive improvement)** — monitors all streams,
   allocates resources to winners, kills underperformers, spawns new agents
   for validated opportunities, and runs the prediction-vs-reality loop.

**The founder's only ongoing jobs:** read the daily digest, do a 1-minute
check-in (energy/pain/fear), and approve consequential actions. Everything
involving money, legal commitments, publishing, or identity **always**
requires founder approval. That is constitutional, not configurable.
