### ONE COMMAND TO START EVERYTHING:

```bash
# On your Oracle Cloud server, run:

```

That's it. The system will:
- Install everything automatically
- Start the 3 simplest revenue streams
- Open a dashboard at http://YOUR_SERVER_IP:8080
- Run 24/7 without you

1. Open dashboard in browser: http://YOUR_SERVER_IP:8080
2. Click "Daily Check-in" - Select your energy (1-5), pain (1-5), fear (1-5)
3. Read your ONE action for the day
4. Click Approve/Reject if something needs your OK
